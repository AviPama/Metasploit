**Attacks on Metasploitable 2 Using Kali Linux**
This project involved identifying and exploiting vulnerabilities in Metasploitable 2, an intentionally insecure Linux-based virtual machine. Using Kali Linux as the attacking machine, two distinct attacks were designed and executed to demonstrate the methods of penetration testing and vulnerability exploitation.

**Project Goals**
To simulate real-world cyberattacks in a controlled environment.
To gain hands-on experience with common tools and techniques used in ethical hacking.
To analyze and document the outcomes of each attack and propose remediation strategies.

**Environment Setup**
Virtual Machines Used:
Kali Linux: The attacker VM, equipped with tools like Metasploit, Nmap, and others for penetration testing.
Metasploitable 2: The vulnerable target VM, containing pre-configured security flaws for testing purposes.
Network Configuration:
Both VMs were connected to a private NAT or Host-Only network for isolated communication.
